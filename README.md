# Bouncy

1. Create the Expo project:
   npx create-expo-app@latest bouncy --template blank
   cd bouncy
2. Install dependencies:
   npx expo install @supabase/supabase-js @react-native-async-storage/async-storage react-native-url-polyfill react-native-safe-area-context
3. Copy App.js and the src/ folder from this zip into the project (replace App.js).
4. Run: npx expo start  (scan the QR code with the Expo Go app)

Supabase: project Bouncy01. For quick testing, turn off
Authentication > Providers > Email > "Confirm email" in the Supabase dashboard.
